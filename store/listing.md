按开发者控制台的页面顺序填写。代码块里的文字可以直接复制粘贴。

## 0. 准备

- 上传包：`dist/bilibili-ambient-light-<version>.zip`（当前版本 1.0.1，用 `pwsh tools/pack.ps1` 生成）

## 1. 新建内容

控制台左侧「内容」→「新增内容」，选择上面的 zip 上传。名称、摘要、图标会从 manifest 自动读取。

## 2. 商品详情（Store listing）

**说明**（详细描述）：

```
在 B 站看视频时，把画面的色彩实时延伸到整个网页背景，营造沉浸式的氛围光效果。

【功能】
• 氛围光：逐帧读取视频画面，把边缘色彩柔和地扩散到页面背景，并自然渐隐
• 自动识别黑边：视频自带的黑边会被跳过，光从画面真正的边缘出发
• 通透页面：开启后页面切换为半透明深色主题，并加上文字阴影，内容依旧清晰
• 宽屏模式同样生效；网页全屏、全屏和小窗播放时自动隐藏，不影响观看
• 可调参数：光晕范围、模糊程度、亮度、饱和度、对比度、渐隐起点与曲线、帧率上限等，调整实时生效
• 三个预设：柔和、沉浸、满屏（默认）

【使用方法】
安装后打开任意 B 站视频页即可看到效果。点击浏览器工具栏上的扩展图标，可以开关氛围光、切换预设和调整参数。

【隐私】
所有处理都在浏览器本地完成。本扩展不收集、不上传、不分享任何数据，只在本地保存你的设置。

【支持作者】
全部功能免费。觉得好用的话，可以点扩展弹窗底部的「请作者喝杯咖啡」，用微信或支付宝打赏；GitHub 项目页也有收款码：https://github.com/Miruko2/bilibili-ambient-light
也欢迎在这里留个评分。

【说明】
本扩展为个人开发的非官方工具，与哔哩哔哩（bilibili）没有任何关联。
```

## 3. 隐私权（Privacy practices）

**单一用途说明**：

```
在 bilibili.com 的视频播放页，根据正在播放的视频画面，实时在网页背景上生成氛围光效果。
```

**storage 权限理由**：

```
用于在本地保存用户在弹出窗口中设置的参数（如开关状态、光晕范围、亮度），以便下次打开视频页时沿用。只保存这些设置，不保存任何浏览数据或个人信息。
```

**主机权限理由**（https://www.bilibili.com/*）：

```
扩展的核心功能需要在 B 站视频页运行内容脚本：读取页面中正在播放的视频画面，在本地计算颜色，把光效绘制到网页背景上，并调整页面样式让光效可见。只在 www.bilibili.com 上运行，不访问其他网站。读取的画面只在内存中处理，不会保存，也不会发送到任何地方。
```

**远程代码**：选「否，我没有使用远程代码」。

- 上面的数据类型全部**不勾选**（扩展不收集任何数据）。

## 6. 提交

右上角「提交审核」。如果不想审核通过后立刻上线，可以取消勾选「审核通过后自动发布」。

## 7. 发布更新

以 1.0.1 为例（弹窗底部新增「请作者喝杯咖啡」和「去商店评分」）：

1. 把 `manifest.json` 里的 `version` 加一，运行 `pwsh tools/pack.ps1`，生成 `dist/bilibili-ambient-light-1.0.1.zip`。
2. 在控制台打开这个扩展，进入「程序包」（Package）页，点「上传新软件包」（Upload new package），选上面的 zip。
3. 在「商品详情」里把「说明」换成第 2 节的最新文字（1.0.1 新增了【支持作者】一段），保存草稿。
4. 权限和数据使用都没有变，「隐私权」页不用改。
5. 「提交审核」。审核期间商店里还是旧版本，通过后已安装的用户会自动更新。
